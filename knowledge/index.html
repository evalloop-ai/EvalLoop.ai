THE LEARNING PATH

From first principles to advanced systems.

01
Foundations
Understand AI, machine learning, LLMs, prompts, outputs, hallucinations, and why evaluation exists.
02
Evaluation Fundamentals
Learn test cases, evaluation criteria, datasets, expected outputs, quality dimensions, and evaluation design.
03
Core Evaluation
Master factuality, relevance, completeness, instruction following, fluency, and other quality dimensions.
04
Methods & Scoring
Explore human evaluation, LLM judges, deterministic checks, classifiers, embeddings, scales, normalization, and aggregation.
05
Test Design
Build useful datasets, golden sets, edge cases, adversarial tests, sampling strategies, and evaluation suites.
06
Model Comparison
Compare models using pairwise evaluation, win rates, disagreement analysis, and evidence-based judgments.
07
Regression Testing
Learn baselines, release gates, thresholds, regression detection, failure analysis, and continuous evaluation.
08
RAG & Grounding
Evaluate retrieval, context relevance, faithfulness, answer relevance, citations, and grounded answers.
09
Safety
Learn toxicity, jailbreaks, harmful content, privacy, bias, safety classifiers, and red-team evaluation.
10
Multimodal & Vision
Evaluate image understanding, visual grounding, generated images, bounding boxes, IoU, precision, recall, and mAP.
11
Conversation & Memory
Evaluate multi-turn conversations, coherence, context retention, memory accuracy, and personal context.
12
Agents
Understand agent trajectories, tool use, planning, task completion, tool errors, and end-to-end evaluation.
13
Production Evaluation
Learn monitoring, production datasets, drift, continuous testing, quality alerts, and evaluation pipelines.
14
Advanced Evaluation
Go deeper into judge calibration, statistical confidence, disagreement, jury evaluation, human gold sets, and benchmark design.
