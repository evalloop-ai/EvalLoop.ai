01 / GETTING STARTED

Start evaluating AI quality.

EvalLoop AI is an evaluation platform designed to measure the quality of AI-generated responses across structured evaluation dimensions.

The platform separates the AI system being tested from the evaluation engine. This allows responses to be generated by a target system and evaluated independently.

01

Generate

Your target AI system produces the response that you want to evaluate.

02

Evaluate

An EvalLoop evaluation engine analyzes the response against defined quality dimensions.

03

Measure

Individual dimension scores are combined into a structured evaluation result.

04

Improve

Use evaluation results to identify weaknesses, compare versions, and improve AI quality.

02 / EVALUATION

How evaluation works.

EvalLoop evaluates an AI response using an evaluation engine and a defined set of quality dimensions.

INFO

EVP.Aureon is the current general-purpose evaluation profile used by EvalLoop. Evaluation profiles are evaluation engines built on top of underlying AI models; they are not represented as independently trained proprietary foundation models.

03 / DIMENSIONS

Six quality dimensions.

The current general-purpose evaluation system analyzes responses across six dimensions.

01
Factuality
Measures whether claims in the response are factually supported and free from significant inaccuracies.
02
Instruction Following
Measures how accurately the response follows the explicit requirements of the prompt.
03
Relevance
Measures whether the response stays focused on the requested task and avoids unnecessary content.
04
Completeness
Measures whether the response sufficiently covers the important requirements of the task.
05
Safety
Measures whether the response introduces meaningful safety, policy, or harmful-content concerns.
06
Fluency
Measures clarity, readability, grammar, and overall linguistic quality.

07 / SECURITY

Security and data handling.

AI evaluation can involve sensitive prompts and generated responses. EvalLoop is designed around separating evaluation infrastructure from the target AI system.

API credentials

API credentials used to connect target systems should be treated as secrets and should not be exposed in client-side code or publicly shared configuration.

Evaluation data

Evaluation requests may contain prompts and model responses. Avoid submitting confidential or sensitive information unless your deployment and data-handling requirements permit it.

Evaluation independence

The target AI system and the evaluation engine serve different roles. The benchmark architecture is designed so that the system being tested can be evaluated independently from the scoring layer.
