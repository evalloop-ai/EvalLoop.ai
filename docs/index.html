01 / GETTING STARTED

Start evaluating AI responses.

EvalLoop AI evaluates an AI-generated response against the original user prompt and, when available, a supplied reference or context.

The current evaluation engine, EVP.Aureon, evaluates responses across six quality dimensions and produces normalized scores from 0 to 100.

Basic evaluation flow

Provide the original prompt, the AI-generated response, and optionally a reference or additional context. EvalLoop AI evaluates the response and returns structured quality scores, detected issues, a summary, and a recommendation.

02 / EVALUATION

Six dimensions.

The current evaluator measures six independent dimensions of AI response quality.

01
Factuality
Measures whether claims are accurate and supported by the available information.
02
Instruction Following
Measures whether the response actually follows the user's requested task, format, constraints, and requirements.
03
Relevance
Measures whether the response directly addresses the user's request without unnecessary or contradictory information.
04
Completeness
Measures whether the important parts of the request were addressed.
05
Safety
Measures meaningful safety, privacy, security, and harmful-content concerns.
06
Fluency
Measures clarity, grammar, readability, coherence, and natural language quality.

Scoring: Every dimension receives an integer score from 0 to 100. The final overall score is calculated by the API as the rounded arithmetic mean of all six dimension scores.

Benchmark profiles

The benchmark system is being designed around specialized suites including General Quality, Reasoning, RAG, Safety, Agent, and Multimodal evaluation.

General Quality is the current benchmark suite and uses EVP.Aureon. Specialized benchmark engines are planned for future releases.

05 / API

Evaluation API.

The EvalLoop AI evaluation API accepts an original user prompt, an AI-generated response, and an optional reference or additional context.

METHOD
POST
ENDPOINT
/api/evaluate
CONTENT-TYPE
application/json
STATUS
AVAILABLE

Request body

The request must contain two required string fields: prompt and response. The reference field is optional.

JSON 
{
  "prompt": "What is the capital of France?",
  "response": "The capital of France is Paris.",
  "reference": "France's capital city is Paris."
}

Request fields

prompt
The original user prompt that the AI was asked to answer.
REQUIRED
response
The AI-generated response that should be evaluated.
REQUIRED
reference
Reference information or additional context used as evidence during evaluation.
OPTIONAL

cURL example

The following example sends an evaluation request directly to the deployed EvalLoop AI API.

SHELL 
curl -X POST "https://YOUR-DOMAIN/api/evaluate" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "What is the capital of France?",
    "response": "The capital of France is Paris.",
    "reference": "France'\''s capital city is Paris."
  }'

JavaScript example

JAVASCRIPT 
const result = await fetch("/api/evaluate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    prompt: "What is the capital of France?",
    response: "The capital of France is Paris.",
    reference: "France's capital city is Paris."
  })
});
const evaluation = await result.json();
console.log(evaluation);

Response

A successful evaluation returns a normalized JSON object containing the overall score, six dimension scores, detected issues, a summary, and a recommendation.

JSON / 200 OK 
{
  "overall_score": 100,
  "overall_text": "Strong response.",
  "scores": {
    "factuality": 100,
    "instruction_following": 100,
    "relevance": 100,
    "completeness": 100,
    "safety": 100,
    "fluency": 100
  },
  "issues": [],
  "summary": "The response accurately answers the user's question.",
  "recommendation": "No major improvements are required."
}

Response fields

overall_score
Overall quality score calculated by the API as the rounded average of the six dimension scores.
0–100
overall_text
Short overall interpretation of the evaluation.
STRING
scores
Object containing the six normalized evaluation dimension scores.
OBJECT
issues
Array of detected meaningful quality issues. Each issue contains type and description.
ARRAY
summary
Concise summary of the evaluation result.
STRING
recommendation
Suggested improvement based on the detected evaluation result.
STRING

Issues

When meaningful quality problems are detected, the issues array contains objects with exactly two fields: type and description.

JSON 
"issues": [
  {
    "type": "Factuality",
    "description": "The response contains an unsupported factual claim."
  }
]

Error responses

The API validates the request before sending it to the evaluation engine and also handles upstream Groq and server errors.

STATUS CONDITION RESPONSE
405 Request method is not POST. Method not allowed
400 Prompt is missing or not a non-empty string. Prompt is required.
400 AI response is missing or not a non-empty string. AI response is required.
500 GROQ_API_KEY is not configured. GROQ_API_KEY is not configured.
502 Groq evaluation request failed. Groq evaluation request failed.
502 Groq returned an empty response. Groq returned an empty response.
502 Groq returned invalid evaluation JSON. Groq returned invalid evaluation JSON.
500 Unexpected server error. Unexpected server error.

Implementation note: The evaluator uses a server-side Groq API credential. The API key is read from the GROQ_API_KEY environment variable and is not part of the client request.

06 / SECURITY

Security by design.

EvalLoop AI keeps the evaluation provider credential on the server rather than exposing it to the browser.

01
Server-side API key The Groq credential is accessed through the Vercel environment variable GROQ_API_KEY.
02
POST-only evaluation endpoint The evaluation endpoint accepts POST requests for evaluation operations.
03
Input validation Required prompt and response values are validated before an evaluation request is sent to the evaluation provider.
04
Normalized output Scores are constrained to the 0–100 range, issues are normalized, and the overall score is calculated deterministically by the API.

For additional information, review the Privacy Policy and AI Usage documentation.
