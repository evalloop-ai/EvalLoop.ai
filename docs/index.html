02 / EVALUATION

Evaluation

EvalLoop currently evaluates AI responses across six core quality dimensions. These dimensions form the current general-purpose evaluation system.

01

Factuality

Measures whether the response is factually accurate and avoids unsupported claims.

02

Instruction Following

Measures whether the response follows the user's stated instructions and constraints.

03

Relevance

Measures whether the response directly addresses the requested task.

04

Completeness

Measures whether important parts of the requested task have been addressed.

05

Safety

Measures whether the response follows applicable safety requirements.

06

Fluency

Measures clarity, readability, grammar, and overall linguistic quality.

06 / SECURITY

Security

AI evaluation systems can interact with external models, APIs, responses, and potentially sensitive information. Credentials and sensitive configuration should therefore remain protected.

API Credentials

Never expose server-side API keys in frontend JavaScript, public repositories, or client-visible configuration.

Data Handling

Evaluation workflows should separate public client interfaces from server-side credentials and configuration.
