01

Getting Started

EvalLoop AI is an evaluation platform for measuring the quality of AI and LLM responses. The platform evaluates responses across defined quality dimensions and returns structured results.

Introduction

The core EvalLoop workflow takes an AI-generated response and evaluates it using an evaluation profile. The current production evaluation profile is EVP.Aureon.

How EvalLoop Works

01 Target AI Generate a response
↓
02 Response Submit the output
↓
03 EVP.Aureon Run evaluation
↓
04 Six Dimensions Measure quality
↓
05 Result Return evaluation

Evaluation Workflow

  1. Provide the AI response to EvalLoop.
  2. Select the available evaluation profile.
  3. The evaluator analyzes the response across supported quality dimensions.
  4. EvalLoop returns the evaluation result.

Quickstart

The simplest way to interact with the current evaluator is through the POST /api/evaluate endpoint.

02

Evaluation

EvalLoop currently evaluates AI responses across six core quality dimensions.

01

Factuality

Measures whether the response is factually accurate and avoids unsupported claims.

02

Instruction Following

Measures whether the response follows the user's stated instructions and constraints.

03

Relevance

Measures whether the response directly addresses the requested task.

04

Completeness

Measures whether important parts of the requested task have been addressed.

05

Safety

Measures whether the response follows applicable safety requirements.

06

Fluency

Measures clarity, readability, grammar, and overall linguistic quality.

05

API

EvalLoop exposes an evaluation endpoint for submitting AI responses to the current evaluator.

POST
/api/evaluate

Evaluation Endpoint

The current endpoint evaluates an AI response across six quality dimensions using the EvalLoop evaluation engine.

Request 

POST /api/evaluate
Content-Type: application/json

Response

The endpoint returns a structured evaluation result generated by the current evaluator. Refer to the evaluator implementation for the exact response structure used by the deployed API.

Current API

The currently implemented evaluation endpoint is /api/evaluate. Additional API capabilities may be introduced as the platform develops.

Authentication

API access and authentication requirements may depend on the deployed EvalLoop environment. Do not expose server-side API credentials in client-side code.

06

Security

Security is an important part of the EvalLoop architecture, particularly when connecting external AI systems and APIs.

API Credentials

API credentials should be treated as secrets. They should not be hard-coded into frontend JavaScript, public repositories, or documentation.

Data Handling

Evaluation workflows should be designed so that sensitive credentials and server-side configuration remain outside publicly accessible client code.
