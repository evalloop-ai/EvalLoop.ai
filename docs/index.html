01 / GETTING STARTED

What is EvalLoop AI?

EvalLoop AI is an AI evaluation and LLM quality platform focused on structured, repeatable measurement of AI system performance.

Instead of treating an AI response as simply correct or incorrect, EvalLoop evaluates multiple quality dimensions and produces structured evaluation signals.

02 / EVALUATION

How evaluation works

EvalLoop separates the AI system being tested from the evaluation engine. This allows a target system to generate responses while a separate evaluation profile measures those responses against defined criteria.

01
Target AI System The model or AI application being tested.
02
Benchmark Dataset Structured prompts and expected evaluation criteria.
03
Candidate Response The response generated by the target system.
04
EVP Evaluation Engine Evaluates the response across selected dimensions.
05
Results Dimension measurements and aggregate benchmark results.
03 / EVALUATION DIMENSIONS

Six core dimensions

The current general-purpose evaluation profile measures six core dimensions of AI response quality.

01

Factuality

Measures whether claims and information in a response are accurate and supported by the available context.

02

Instruction Following

Measures whether the response follows the user's stated requirements and constraints.

03

Relevance

Measures whether the response directly addresses the requested task without unnecessary deviation.

04

Completeness

Measures whether the response covers the important parts of the requested task.

05

Safety

Measures whether responses appropriately handle safety-sensitive requests and applicable constraints.

06

Fluency

Measures clarity, readability, grammar, and overall quality of expression.

04 / PLATFORM ARCHITECTURE

Separate the system from the evaluator.

EvalLoop is designed around a clear separation between the AI being tested and the engine performing evaluation. This distinction is central to the platform's benchmark architecture.

EVALUATION PRINCIPLE

The target AI generates the answer. The evaluation engine judges the answer. Keeping these responsibilities separate makes the evaluation workflow easier to inspect and extend.

08 / SECURITY

Security architecture

AI evaluation often requires access to model endpoints and credentials. EvalLoop is designed to keep sensitive credentials outside public frontend code.

CREDENTIAL PRINCIPLE

Permanent API credentials should never be placed directly in frontend JavaScript, HTML, or public repositories. Production integrations should process credentials through secure server-side infrastructure.

SEC / 01

Server-side processing

Sensitive operations should be handled by backend infrastructure rather than public client code.

SEC / 02

Credential protection

API credentials should not be committed to Git repositories or exposed through client-side source code.
