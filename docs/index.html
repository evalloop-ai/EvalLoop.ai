01 / GETTING STARTED

Start evaluating AI quality.

EvalLoop AI is an evaluation platform designed to measure the quality of AI-generated responses across structured evaluation dimensions.

The core architecture separates the AI system being tested from the evaluation engine. This allows responses to be evaluated independently.

01 / GENERATE

Generate

Your target AI system produces the response that you want to evaluate.

02 / EVALUATE

Evaluate

An EvalLoop evaluation engine analyzes the response against defined quality dimensions.

03 / MEASURE

Measure

Individual dimension scores are combined into a structured evaluation result.

04 / IMPROVE

Improve

Use evaluation results to identify weaknesses, compare versions, and improve AI quality.

02 / EVALUATION

How evaluation works.

EvalLoop evaluates an AI response using an evaluation engine and a defined set of quality dimensions.

TARGET AI System under test
→
RESPONSE Generated output
→
EVP.AUREON Evaluation engine
→
6 DIMENSIONS Quality analysis
→
RESULT Scores + analysis
NOTE

EVP.Aureon is the current general-purpose evaluation profile used by EvalLoop AI. Evaluation profiles are evaluation engines backed by underlying AI models and are not represented as independently trained proprietary foundation models.

03 / DIMENSIONS

Six quality dimensions.

The current general-purpose evaluation system analyzes responses across six dimensions.

01
Factuality
Measures whether claims in the response are factually supported and free from significant inaccuracies.
02
Instruction Following
Measures how accurately the response follows the explicit requirements of the prompt.
03
Relevance
Measures whether the response stays focused on the requested task.
04
Completeness
Measures whether the response sufficiently covers the important requirements of the task.
05
Safety
Measures whether the response introduces meaningful safety or harmful-content concerns.
06
Fluency
Measures clarity, readability, grammar, and overall linguistic quality.

06 / API

Evaluation API.

EvalLoop exposes an evaluation endpoint for sending an AI response to the current general-purpose evaluator.

POST /api/evaluate
Evaluate an AI response across the current six quality dimensions using EVP.Aureon.

Request

JSON 
{
  "prompt": "Explain photosynthesis.",
  "response": "Photosynthesis is..."
}

Response

JSON 
{
  "evaluator": "EVP.Aureon",
  "factuality": 9,
  "instruction_following": 9,
  "relevance": 9,
  "completeness": 8,
  "safety": 10,
  "fluency": 9
}
NOTE

The API contract should remain aligned with the current implementation of the EvalLoop evaluation endpoint. Authentication and production limits may evolve as the platform develops.

07 / SECURITY

Security and data handling.

AI evaluation can involve sensitive prompts and generated responses. EvalLoop separates the target AI system from the evaluation layer.

CREDENTIALS

API credentials

Credentials used to connect target systems should be treated as secrets and should not be exposed in client-side code.

DATA

Evaluation data

Evaluation requests may contain prompts and model responses. Avoid submitting confidential information unless your deployment requirements permit it.

ARCHITECTURE

Evaluation independence

The target AI system and evaluation engine serve different roles within the evaluation architecture.

PLATFORM

AI usage

Review the EvalLoop AI usage documentation for information about how AI-assisted functionality is used across the platform.
