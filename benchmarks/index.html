METHODOLOGY

Benchmarks need context.

A benchmark number is only meaningful when the test conditions and evaluation criteria are understood.

01

Defined test sets

Benchmark tasks can be organized into controlled datasets with clearly defined inputs, expected outputs, or evaluation criteria.

02

Repeatable evaluation

The same evaluation configuration should be reusable so changes in models, prompts, or systems can be measured consistently.

03

Multiple dimensions

Quality can involve multiple dimensions such as factuality, relevance, completeness, safety, instruction following, and fluency.

04

Transparent reporting

Benchmark reports should identify the scope, dataset, methodology, evaluation model or logic, and important limitations.
